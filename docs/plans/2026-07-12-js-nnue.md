# JS-NNUE Evaluation Implementation Plan

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Ersetze die Handcrafted-Eval (`evaluateBoard`) durch ein kleines neuronales Netz in reinem JS (kein WASM), das aus Self-Play-Spielen gelernt wird. Ziel: ~80-120 Elo stärker als die aktuelle Eval, deploy-sicher auf GitHub Pages.

**Architecture:** Ein kleines FFN (Feed-Forward-Netz) mit dense Input-Encoding. Die Position wird als 660-dimensionaler Feature-Vektor encodiert (66 Zellen × 10 Werte: 6 Piece-Type-OneHot + 3 Faction-OneHot + 1 Occupied). Das Netz (660→128→32→1, ReLU/tanh) wird offline in Node aus Self-Play-Spielen trainiert; die Gewichte liegen als JSON im Deploy und werden zur Laufzeit in `Float32Array` geladen. `evaluateBoard` bleibt als Fallback/default; ein Setting schaltet auf NNUE um. KEINE WASM-Abhängigkeit — reines JS mit TypedArray-MatMul.

**Tech Stack:** TypeScript, Vitest, Float32Array-MatMul, Node-Trainer-Script (Self-Play + Gradient-Descent), JSON-Gewichtsdatei unter `js/weights/`.

```ts
// js/nnue.ts
import { FACTION } from "./board.ts";
import { PIECE_TYPE } from "./pieces.ts";
import { Game } from "./game.ts";
import { Hex } from "./hex.ts";

export const NNUE_INPUT_DIMS = 660; // 66 cells x 10 features
const CELL_COUNT = 66;
const PIECE_TYPES = ["king", "queen", "rook", "bishop", "knight", "pawn"] as const;
const FACTIONS = [FACTION.FIRE, FACTION.WATER, FACTION.NATURE] as const;

// Precompute the canonical cell ordering (same order as generateBoard iteration).
function buildCellOrder(): Hex[] {
  const cells: Hex[] = [];
  const N = 5;
  for (let r = 0; r <= N; r++) for (let q = -r; q <= 0; q++) cells.push(new Hex(q, r));
  for (let d = 1; d <= 2; d++) { const r = N + d; for (let q = -N - d; q <= 0; q++) cells.push(new Hex(q, r)); }
  for (let d = 1; d <= 2; d++) { const q = d; for (let r = -d; r <= N; r++) cells.push(new Hex(q, r)); }
  for (let d = 1; d <= 2; d++) { const s = d; for (let r = -d; r <= N; r++) cells.push(new Hex(-r - s, r)); }
  return cells;
}
const CELL_ORDER = buildCellOrder();
const CELL_INDEX = new Map(CELL_ORDER.map((h, i) => [h.key, i]));

export interface NNUEWeights {
  w1: Float32Array; // [128 x 660]
  b1: Float32Array; // [128]
  w2: Float32Array; // [32 x 128]
  b2: Float32Array; // [32]
  w3: Float32Array; // [1 x 32]
  b3: Float32Array; // [1]
}

let WEIGHTS: NNUEWeights | null = null;

export function loadNNUEWeights(w: NNUEWeights): void {
  WEIGHTS = w;
}

export function encodePosition(game: Game, perspective: Faction): Float32Array {
  const vec = new Float32Array(NNUE_INPUT_DIMS);
  for (const p of game.pieces) {
    if (!p.alive) continue;
    const ci = CELL_INDEX.get(p.pos.key);
    if (ci === undefined) continue;
    const base = ci * 10;
    vec[base + 9] = 1; // occupied
    const ti = PIECE_TYPES.indexOf(p.type as any);
    if (ti >= 0) vec[base + ti] = 1;
    const fi = FACTIONS.indexOf(p.faction);
    if (fi >= 0) vec[base + 6 + fi] = 1;
  }
  return vec;
}

function relu(x: number): number { return x > 0 ? x : 0; }

export function evaluateNNUE(game: Game, perspective: Faction): number {
  if (!WEIGHTS) throw new Error("NNUE weights not loaded");
  const x = encodePosition(game, perspective);
  const h1 = new Float32Array(128);
  for (let i = 0; i < 128; i++) {
    let s = WEIGHTS.b1[i]!;
    for (let j = 0; j < NNUE_INPUT_DIMS; j++) s += WEIGHTS.w1[i * NNUE_INPUT_DIMS + j]! * x[j]!;
    h1[i] = relu(s);
  }
  const h2 = new Float32Array(32);
  for (let i = 0; i < 32; i++) {
    let s = WEIGHTS.b2[i]!;
    for (let j = 0; j < 128; j++) s += WEIGHTS.w2[i * 128 + j]! * h1[j]!;
    h2[i] = relu(s);
  }
  let out = WEIGHTS.b3[0]!;
  for (let j = 0; j < 32; j++) out += WEIGHTS.w3[j]! * h2[j]!;
  return Math.tanh(out) * 1000; // scale to centipawn-like range
}

// For tests only
export function randomWeights(): NNUEWeights {
  const r = (n: number) => { const a = new Float32Array(n); for (let i = 0; i < n; i++) a[i] = Math.random() * 0.1; return a; };
  return { w1: r(128 * 660), b1: r(128), w2: r(32 * 128), b2: r(32), w3: r(32), b3: r(1) };
}
```

```ts
export function loss(w: NNUEWeights, batch: { vec: Float32Array; label: number }[]): number {
  let s = 0;
  for (const { vec, label } of batch) {
    const pred = forward(w, vec);
    s += (pred - label) ** 2;
  }
  return s / batch.length;
}

export function trainStep(w: NNUEWeights, batch: { vec: Float32Array; label: number }[], lr: number): number {
  // Vanilla SGD on the batch (full-batch gradient)
  const grad = zeroGrads(w);
  for (const { vec, label } of batch) {
    backward(w, vec, label, grad);
  }
  applyGrads(w, grad, lr / batch.length);
  return loss(w, batch);
}
```

(`forward`/`backward`/`zeroGrads`/`applyGrads` are the autodiff-free manual gradients for the 3-layer net — implement with explicit chain rule. Keep it small.)

## Pitfalls

- **Regression-Safety:** `evaluateBoardNNUE` muss default auf `evaluateBoard` zurückfallen (Flag off). Niemals die bestehende Eval im minimax/quiesce hardcoded ersetzen — das bricht die 646 Tests und riskiert Silent-Regressionen.
- **TS-Import in Node:** `scripts/train-nnue.mjs` kann `.ts` nicht direkt importieren. Entweder `tsx` als devDep nutzen (`npx tsx script.ts`) oder das Netz + Training in `.mjs` duplizieren. Empfohlen: `tsx` devDep (klein, keine Runtime-Dep).
- **Gewichtsdatei-Größe:** 88k Parameter × 4 Bytes (Float32) = ~350KB JSON (base10). Das ist akzeptabel für GitHub Pages, aber der fetch sollte async + cached sein (nicht blockierend beim Start).
- **Self-Play-Diversität:** Wenn NNUE nur gegen `evaluateBoard` spielt, lernt es nur dessen Schwächen. Für robuste Eval: auch NNUE-vs-NNUE-Spiele mischen (nach ein paar Iterationen).
- **Overfitting auf kleine Boards:** 66 Zellen sind wenig — das Netz könnte auswendig lernen statt generalisieren. Regularisierung (weight decay) im Trainer empfohlen.
- **Elo-Messung:** Vor dem Release einen kleinen Match-Runner (Engine-vs-Engine) bauen, um den Elo-Gewinn zu verifizieren (nicht nur "Tests grün"). Nutze `calculateBestMove` Head-to-Head über N Spiele.
